# Student Performance Analyzer — Module 01

A beginner-friendly Python mini-project for **Python & Data Science Fundamentals**.

## What it does
- Reads student names and scores from a CSV file.
- Calculates the class average.
- Finds the top performer.
- Counts passed students and students who need improvement.
- Displays individual results.
- Saves a summary to `performance_report.txt`.

## Python concepts demonstrated
- Variables and data types
- Lists and dictionaries
- `for` loops and `if/else`
- Functions
- File handling with CSV and text files

## Requirements
- Python 3 (no extra packages required)

## How to run
1. Download or clone this repository.
2. Keep `main.py` and `student_scores.csv` in the same folder.
3. Open a terminal in that folder.
4. Run:

```bash
python main.py
```

If your computer uses the `python3` command, run `python3 main.py`.

## Sample output
```text
===== STUDENT PERFORMANCE ANALYZER =====
Students analyzed: 6
Class average: 73.33
Top performer: Diya (92.0)
Passed: 5
Needs improvement: 1
```

The program also creates `performance_report.txt`.

## Dataset
`student_scores.csv` is a small sample dataset created for learning and demonstration. It is not real student data.
